# 🌊 海洋塑料污染数据可视化平台

> 2025-09 独立模式更新：平台已完成“前端完全脱离 Python”改造。默认运行不再依赖任何本地后端或端口探测，所有页面（含漂流模拟）均可直接以静态资源方式部署（本地双击或放入任意静态服务器）。

> 新增 legacy/ 目录：所有可选后端脚本 (Streamlit / API / 瓦片缓存 / 完整依赖清单) 已迁移到 `legacy/`，如无科研扩展需求可忽略。

核心变化：
1. 取消 Streamlit 自动端口扫描与跳转逻辑；导航按钮直接打开 `drift_simulation.html`。
2. 保留 `app_streamlit.py` / `simulation_api.py` 作为可选扩展（需要真实后端或批量数据代理时再启用）。
3. 新增“前端独立模式 / 离线本地文件模式”徽章：顶部导航右侧自动显示当前运行模式。
4. file:// 离线访问时自动启用所有数据的本地/模拟回退，不阻塞图表渲染。
5. 文档与代码中标注 legacy（可选）后端部分，默认无需执行 Python。

如果你只需要前端演示：直接打开 `main.html` 即可开始，无需安装依赖或运行任何命令。

如果你希望启用高级特性（真实大规模数据聚合、OBIS 代理、NetCDF 解码等），可选择性启动 Python 组件；否则可以忽略它们。

## 🚀 快速启动

### 方法一：纯前端静态访问（推荐）
直接双击 `main.html`（或使用任意静态文件服务器，如 `python -m http.server` / `npx serve`）。

### 方法二：（可选）一键启动含 Python 扩展
若需运行 legacy Streamlit / 服务端增强，再双击 `start_platform.bat` 或在命令行执行：
```bash
python start_platform.py
```

### 方法二：使用启动指南
1. 双击打开 `launch_guide.html`
2. 按照页面指示操作

### 方法三：手动启动
1. **选择正确终端并进入项目根目录**  
   Windows 推荐使用：
   - VS Code 内置终端：终端面板中新建/选择名称为 `powershell` 的会话；或
   - 系统 Windows PowerShell（开始菜单输入“PowerShell”回车）
   
   确认当前目录包含 `app_streamlit.py`：
   ```powershell
   Get-ChildItem app_streamlit.py
   ```
   若未找到，请先切换到项目目录，例如：
   ```powershell
   cd "C:/Users/MECHREVO/Desktop/文件/大二上/比赛项目"
   ```

2. **（可选）激活你的 Python 环境**  
   如果你创建了虚拟环境：
   ```powershell
   .\.venv\Scripts\Activate.ps1   # 例：本地 venv
   # 或 Conda
   conda activate your_env_name
   ```

3. **(可选) 启动 Streamlit 漂流模拟应用（legacy）**  
   ```powershell
   streamlit run app_streamlit.py --server.port 8526
   ```
   说明：
   - 如 8526 被占用，可改成 8525 / 8520 / 8501~8505
   - 终端启动成功后保持窗口不要关闭
   - VS Code 内置终端与外部 PowerShell 效果相同，任选其一即可

4. **打开主界面**：
   直接双击 `main.html` 或在浏览器访问（建议与上一步在同一台机器）。

5. **主界面跳转逻辑（已简化）**：
   - “详细漂流演示”按钮现在始终直接打开 `drift_simulation.html`
   - 不再探测本地端口；Streamlit 版本若在运行需自行在浏览器输入端口访问

### 方法四：直接访问增强版模拟
启动HTTP服务器后，直接访问：
- `http://localhost:端口号/drift_simulation.html` - 包含所有最新功能
- `http://localhost:端口号/debug_drift.html` - 调试版本
- `http://localhost:端口号/drift_minimal.html` - 简化版本

## ✨ 最新增强功能

`drift_simulation.html` 包含以下高级功能：
- ✅ **30秒2%粒子消除**: 每30秒随机消除2%的粒子，模拟塑料降解
- ✅ **无重生机制**: 粒子死亡后不再重生，更真实的模拟
- ✅ **1分钟洋流刷新**: 洋流场每分钟自动更新，模拟动态海洋环境
- ✅ **潮汐效应**: 包含潮汐循环对粒子运动的影响
- ✅ **海岸反射**: 粒子碰到海岸时的真实反射行为
- ✅ **面向海洋的初速度**: 从陆地出发的粒子朝向海洋方向
- ✅ **90度洋流方向限制**: 洋流方向变化平滑，不超过90度

### 📡 主界面真实数据接入（保留前端独立 + 回退策略）
主面板多项图表已由模拟改为真实在线数据源：

- 年度误管理塑料趋势 / 国家占比：数据来源于 **OWID (Our World In Data) Mismanaged Plastic Waste** 数据集（按需裁剪最近20年，并对 Top5 国家做归一化处理）。
- 洋流速度分布与指标概览：来源于 **OSCAR (Ocean Surface Current Analysis in Real-time)** 样本数据（客户端抽样统计速度区间与基础指标）。
- 自动刷新：垃圾与洋流两类真实数据每 **15 秒** 后台刷新一次（并发 + 并发锁防止重叠），顶部状态栏显示最新刷新结果与耗时。
- 失败与回退：若网络失败或被 file:// 环境阻止，则保留上一次图表数据；不会抛出阻塞性错误。

### 🧬 沿海城市生物类群减少（新接入）
图表“沿海城市生物类群减少”采用两级数据来源策略：

1. 优先调用数据服务接口 `getCoastalCityBiodiversityLoss`：
   - 设计目标：未来可基于 **OBIS** 物种出现记录（occurrence/taxon stats）对每个沿海城市附近（矩形缓冲区）的近年记录数进行类群聚合，计算年度差异或近似“减少量”。
   - 当前阶段：由于浏览器直连多区域多请求存在速率与跨域限制，暂以内置模拟聚合（随机生成不同城市主要类群计数）占位。
2. 回退到本地 CSV `china_coastal_marine_bio_loss.csv`：
   - 若接口失败或离线（file://）模式，自动解析 CSV。
   - 解析逻辑支持中文列名：城市/年份/生物类别/减少数量。
   - 取最新年份，对 “城市-生物类别” 组合聚合后按减少数量取 Top8 展示。

脚注标识：
 - “数据服务(模拟 OBIS 聚合)” 表示来自接口（占位模拟）。
 - “本地CSV” 表示使用离线数据文件。

未来计划（可选）：
 - 使用后端代理批量请求 OBIS，计算真实年度减幅：loss = max(0, (prevYearCount - curYearCount)).
 - 支持城市/年份下拉过滤与堆叠模式（城市为组、类群堆叠）。
 - 为条目添加链接，点击跳转至 OBIS / 或 CSV 中“详情链接”列。

注意：在离线或受限网络下，系统会输出警告并继续显示最后一次成功或占位图表，不影响其它本地功能。

## 🛠️ 故障排除

### 端口占用问题
如果遇到端口被占用，可以：
1. 尝试不同端口：8526, 8525, 8520, 8501-8505
2. 手动关闭现有Streamlit进程
3. 使用任务管理器结束python进程

### 跳转相关
当前版本不再自动端口扫描；按钮仅打开内置前端模拟页面。需要访问后端（若启动）请自行输入 URL（例：`http://localhost:8526`）。

### 性能优化
- 降低粒子数量可提高性能
- 关闭不需要的背景动画
- 使用Chrome浏览器获得最佳体验
- 若频繁刷新导致网络压力或想手动控制，可在 `main.js` 中搜索 `autoRefreshRealData` 注释掉 `setInterval` 行，即可关闭 15 秒自动刷新，再通过开发者工具手动执行：
   ```js
   chartManager.createRubbishChart(true); chartManager.createOceanCurrentChart(true);
   ```
